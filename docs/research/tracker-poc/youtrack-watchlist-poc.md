# YouTrack Movary watchlist experiment

The app candidate keeps a read-only Movary observation in a separate current-user extension property scoped by project. It does not change Movary, tracker records, watched history, or local POC preferences. Absence is unknown, not an assertion that a film is off the watchlist. The project list only reconciles against visible records and flags unmatched or title-different entries. Preparing an unmatched film fills the Add form but does not create a record or call a provider.

The source observation and its completeness status must be existing private project-local files. `youtrack_watchlist_import.py --snapshot <path>` previews counts; `--apply --backup <new-private-path>` imports after making and verifying an owner-only full-property backup. The owner is bound to the current YouTrack account, but the source snapshot alone does not independently prove which Movary account supplied it. Verify its provenance before importing. The observed source time must not move backwards. Source dates with no timezone remain unqualified.

To recover, `youtrack_watchlist_recovery.py export <new-private-path>` exports the current complete property. Then `youtrack_watchlist_recovery.py restore <backup> --expected <current-export>` previews and `--apply` restores exactly after checking account and current value; readback must match. Both paths must be within a project-local owner-only directory. Stop concurrent writers while importing or recovering: the expected-value guard is not demonstrated to be atomic compare-and-swap.

A pinned YouTrack isolated test used a distinct fictional-only app and user property with the FILMPOC project. Absent initial state, actual project access, fictional import/readback, repeat, stale and changed-value guards, and restore passed. The main app's full watched-property export and visible preferences, settings, and usages matched in-memory hashes before and after. Restricted-user denial was checked with fictional in-process users, not a second live account. The main app candidate and real watchlist have not been updated as part of this test.
