## Decision and remaining measurements

Current native Movie of the Night storage permission and public request budget are
now evidenced; the earlier blanket statement that its retention policy was
unverified is superseded by this narrow finding. TMDB history rights, actual
provider account balances/plans, publication permissions for any proposed data
export, third-party content rights and the intended AI-related use remain
unresolved where identified above. Do not promote these unknowns into either
permission or denial.

The [first observation](live-20261030.md) still reports 225 successful TMDB
requests with no quota headers; this audit adds **zero provider API requests**.
It does not change those observations, confer rights retroactively, or verify
monetary charges. It creates no catalog fixtures, retention scheduler or new
runtime dependency. B4 still needs Movie of the Night access and applicable-use
assessment, two genuinely later observation dates using the frozen manifest,
first-party transaction/link checks and intended account/ad-tier evidence.
[ADR 0008](../../adr/0008-availability-providers.md) stays provisional; no provider
superiority, polling cadence or Gate B acceptance is claimed.

Validation: Ruff check, formatting, ty and pytest passed (333 passed, one opt-in
integration test skipped); whitespace diff check passed. This documentation-only
change adds no tests or runtime dependencies.


## Public browser follow-up: TMDB terms now readable

Later on 2026-10-30, the signed-out connected browser rendered the
[canonical API terms](https://www.themoviedb.org/api-terms-of-use) directly.
The web reader remained robots-denied; no restriction was bypassed and no
new agreement was accepted. The page displays **October 20, 2023** as its last
update. This is new access to that document, not evidence of a new policy.

Section 1.C limits cached information to **six months** and restricts derivatives
and use in connection with an ML/AI-based application, including training.
Section 1.D requires use to cease and cached content to be purged when the
license terminates. Section 2.A requires a written agreement for commercial use
and lists chatbot use and model training/validation among its examples. Section
3 requires the logo and a prescribed nonendorsement notice. The earlier ledger's
unknown cache duration is superseded by this bounded six-month cap; it does not
establish a right to retain immutable history indefinitely. This is a terms
assessment, not a legal certification of the intended use.

The deterministic provider comparison neither trains nor evaluates a model.
The broader AI-application wording still needs assessment before adopting an
AI-based product integration; an API key alone is not an exception. Do not
conflate that provision with the narrower Movie of the Night model-use clause.
No additional TMDB request was made during this browser investigation. Local
Oct 30–Nov 1 study observations have a conservative **2027-04-30** TMDB cache
deadline, subject to earlier termination or other applicable restrictions.
The operational retention/deletion requirement is handed to C8; no source files
were deleted and no automatic purge was installed by this research supplement.
The local factual receipt and dated-run configurations remain ignored, with
no credentials or provider responses committed.
