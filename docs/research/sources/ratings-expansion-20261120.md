# Ratings and critic context expansion, November 20, 2026

IMDb's personal-use daily ratings file remains the practical baseline for the expanded private library. It provides IMDb identity, weighted rating and vote count in one streamed join. Its companion basics/akas/crew files supply formats and alternate-title evidence when needed. Join by an independently established ID. Publication of a title suggestion should remain possible while a rating is unknown. [IMDb non-commercial datasets](https://data.imdb.com/non-commercial-datasets/)

Retain the current RT critics/audience and MC critics/users slots and their original units alongside the normalized display. A Tomatometer is the proportion of positive professional reviews, while a Metascore is a weighted critical average. The Popcornmeter has a minimum rating threshold and verified-ticket status is a separate attribute. Equal normalized numbers consequently preserve different meanings. Do not turn an unpublished score or absent feed row into zero. [RT FAQ](https://www.rottentomatoes.com/faq), [Metacritic explanation](https://www.metacritic.com/about-us/)

Wikidata is a useful partial, explicitly derivative score source. Its observations need metric/method, sample count where supplied, point-in-time qualifier, QID, original publisher link and retrieval time. It has no published completeness or freshness guarantee for the six requested score slots. The current POC's RT method filter and MC audience-unit filter prevent some critic/user confusion, but many correct audience scores remain absent upstream. A publisher observation dated today should supersede an older feed observation, while a later feed observation should supersede the snapshot. An undated value cannot establish that it is newer. Keep failed refreshes visible and retain the last verified values.

Rotten Tomatoes' licensing page directs application/API/feed integrations through its business proposal review and requires links to the corresponding title pages. A source list with RT links does not imply that the public RT scores have been joined or refreshed. A recurring direct-site crawler is not an established licensed feed. [RT licensing](https://www.rottentomatoes.com/help_desk/licensing)

MDBList currently documents single and batch lookups by IMDb/TMDB and an updates API. The free account allowance is 1,000 requests daily with separate short-window caps, and 429 responses include retry guidance. The local POC has only historical HTTP 403 observations, so live schema, account access and sustained coverage remain unverified. Batch reads could reduce work after access succeeds. Do not claim an available integration from documentation alone. [MDBList API](https://api.mdblist.com/docs/)

Letterboxd's API access page explicitly excludes private/personal, recommendation, data-analysis and LLM/GPT projects from current access grants. Its FAQ separately permits displaying film ratings and describes an iframe option. This makes a linked/embedded rating a potential user-facing enhancement, while native API access is unavailable under the published application criteria. No application or credential request was sent. [API access](https://letterboxd.com/api-beta/access/), [rating display FAQ](https://letterboxd.com/faq/)

## Integration findings

The existing `comparison_ratings.imdb_matches` makes metadata availability the initial gateway to all scores. An independently verified Wikidata QID with unique IMDb/TMDB identifiers can establish the work before a poster request succeeds. The private patch `ratings/ratings.patch` adds that route and allows `wikidata_id` as a QID or URL and `imdb_id` as an exact identifier. It rechecks all supplied triples against Wikidata and rejects ambiguous/conflicting pairs. The patch uses POST for long input sets and preserves the existing last-successful-value path. A missing metadata policy returns an empty metadata-derived set so supplied public pairs can still proceed. The additional identity query is a bounded background request. The existing global crosswalk fetch could later be reused to remove that duplicated query.

The patch passed `git apply --check` against the deployed worktree. Its proposed public-triple matcher was exercised in memory with an exact pair, two conflicting TMDB IDs on one QID and a mismatched IMDb ID. No deployed file was edited by this review. A real network run remains necessary after integration.

## Critics and dependence

Keep one stable critic identity across appearances in different publishers. Ryan Swen's Slant author profile identifies his byline and professional affiliation. Film Comment identifies Amy Taubin as a contributing editor. Jonathan Rosenbaum's own biography identifies his earlier Chicago Reader employment. These identities justify cross-publication joins while preserving the original publication records. Affiliation, self-described geography and a film's country of production require separate fields. Never infer nationality from name or current publisher. [Swen profile](https://www.slantmagazine.com/author/rswen/), [Film Comment masthead](https://www.filmcomment.com/about/), [Rosenbaum biography](https://jonathanrosenbaum.net/2023/04/bio/)

BFI, Film Comment and Film Stage aggregate lists represent a published aggregation. Individual ballots can add identified critics, but the aggregate itself must not count again as another person endorsing each underlying vote. The same applies to TSPDT when it compiles those polls. Preserve ranked versus unranked and tied positions. Annual list year can represent a local release year or viewing year and cannot substitute for production year.

## Original retrospective corpus

Jonathan Rosenbaum publishes his personal canon in three parts, reproducing his 2004 book appendix. His declared inclusion criteria cover shorts, features, animation, video and some television works, giving the project a substantial retrospective original source beyond current US releases. The display is chronological, and asterisks mark a favored subset. These are unranked selections. [Part one](https://jonathanrosenbaum.net/2024/01/1000-favorites-a-personal-canon/), [part two](https://jonathanrosenbaum.net/2024/01/1000-favorites-a-personal-canon-part-two/), [part three](https://jonathanrosenbaum.net/2024/01/45251/)

The private `ratings/rosenbaum-canon.json` retains 990 film-line factual records with source URLs, year labels, raw director assertions, chronological positions and unresolved IDs. The advertised scope is 1,000 selections, so the file is explicitly marked `requires_review`. Multi-work entries, abbreviations and year ranges need reconciliation before claiming complete work coverage or matching IDs. Two continuation markers are retained as parser discrepancies. No article prose or article body was saved. The payload records the original document SHA-256 per part. It should remain research input until its count discrepancy and identities are reviewed.

The 2022 Sight and Sound Wikidata item has only one film backlink through `described by source` at retrieval, so it cannot reconstruct the poll. The Wikipedia article transcribes only the top ten critics' entries and eleven tied directors' entries, making it unsuitable for importing a complete 100-film poll. Full-primary-source edition acquisition is required. [Wikidata poll item](https://www.wikidata.org/wiki/Q115577992)


## Personal-canon completeness follow-up

A second examination of every nonempty source-list paragraph recovered three entries hidden beside another film in a single HTML paragraph. The omitted entries were *Stalker*, *La cabale des oursins* and *Happy Together*. The corrected visible counts are 351, 354 and 288, totaling 993. All remaining nonempty lines within the chronological list boundaries were retained. Two continuation markers were excluded. No seven additional film entries were found.

The new private `ratings/rosenbaum-sources.json` describes the complete visible scope of each web part and explicitly records that the author’s advertised 1,000-film book count remains unreconciled. Its overall coverage remains intentionally partial. Grouped works and series remain single published observations. Title-internal parentheses and the source’s malformed citation delimiter for *Safe* are handled without changing its factual title or director. *The King of Comedy* lacks a director in this transcription, so its director remains unknown.


The independent original-page audit checked every visible entry and identified 39 field corrections. These remove reference abbreviations from director fields, recover translated-title aliases and version notes, and preserve the literal asterisk in *Corpus Callosum*. The original factual source lines remain unchanged in the private bundle, and a correction ledger records each before/after assertion. The source shows 104 favored-subset marks, despite describing a hundred favorites. The marks remain unweighted source facts, and the discrepancy is explicit.
